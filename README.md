# 🏛️ Mermer Üretim & Stok Takip Sistemi

Bu proje, mermer ocaklarından gelen ham blokların kesiminden, cilalanmasına, kasalanmasından sevkiyatına kadar olan tüm süreçleri yöneten T-SQL ve Python tabanlı bir ERP/Stok Takip sistemidir.

## 🛠️ Teknolojiler
- **Veritabanı:** MS SQL Server 2022 (Docker)
- **Veritabanı Programlama:** T-SQL (Stored Procedures, Triggers, Views)
- **Kullanıcı Arayüzü:** Python (Streamlit)
- **Versiyon Kontrolü:** Git & GitHub
